# torqueJY32.github.io

Personal site design study inspired by Haneda Airport's departure wayfinding.

## Files

- `index.html` contains the page structure.
- `assets/css/site.css` contains the visual system and responsive layout.
- `assets/js/content.js` contains the multilingual copy and board rows.
- `assets/js/site.js` renders the page and handles the board and language controls.

The site stays framework-free so GitHub Pages can serve it directly. There is no build step.
